# AGENTS.md

## What this repo is
- Personal, single-machine NixOS configuration ("Haruka"), not a reusable library or multi-host flake. Host `yozora`, user `cherr`, platform `x86_64-linux`.
- `flake.nix` is the only entrypoint: `nixosConfigurations.yozora` is a `nixpkgs.lib.nixosSystem` with `specialArgs = { inherit inputs; }`, so modules can use `inputs.<name>` directly.
- System modules: home-manager, Noctalia / noctalia-greeter / umbriel / luciole, sops-nix, spicetify-nix, then local `hardware-configuration.nix`, `home`, `modules`.
- `flake.lock` pins all inputs. No `formatter` output, no `checks` output, no devShell.

## Layout and ownership
- `flake.nix` / `flake.lock` — inputs; three Cachix substituters + trusted keys in `nixConfig`; the `yozora` system.
- `hardware-configuration.nix` — generated by `nixos-generate-config`; real disk UUIDs (btrfs root/home/nix subvolumes, vfat `/boot`, swap), Intel microcode, `hostPlatform`. Don't hand-edit; regenerate on the target machine.
- `modules/` — NixOS side. `default.nix` is the import list. `system.nix`: hostname, `stateVersion`, unfree, Nix settings, latest kernel + systemd-boot, Asia/Bangkok locale, Wayland/Qt env vars, graphics, Bluetooth, tablet driver. `desktop.nix`: gpu-screen-recorder, umbriel, noctalia + recommended services, noctalia greeter with passwordless sync for `cherr`, keyring/PAM. `font.nix`: font packages + `haruka-font-pack` built from `assets/fonts`, default font fallbacks. `overlays.nix`: builds `mizuki-psekai-cursor` from `assets/cursors`. `packages.nix`: system packages, fish, steam/gamemode, spicetify extensions/snippets, `nix-ld`, `nh`, luciole. `services.nix`: pipewire, openssh, flatpak, sunshine, syncthing, keyd mappings, udev rules, gvfs/upower. `sops.nix`: secret wiring. `users.nix`: `cherr` user + groups, initial password, trusted user, sudo config.
- `home/` — Home Manager side. `default.nix` configures `useGlobalPkgs = true`, `useUserPackages = true`, `backupFileExtension = "backup"`, user `cherr`, `home.stateVersion = "26.11"`, imports `inputs.umbriel.homeModules.default` plus local modules, and defines/injects `mkSymlink`. `appearance.nix`: cursor, GTK/Adwaita, Papirus icons, Qt/qt5ct/qt6ct. `dotfiles.nix`: symlink registry. `programs.nix`: btop, cava, opencode, yazi, fastfetch, zoxide, starship, git signing, fish aliases/abbrs, Obsidian, VS Code, Kitty. `session.nix`: xsession, umbriel, xdg portals, keyring.
- `dots/` — live-editable configs mirrored into XDG paths via symlinks. `config/` has umbriel, yazi, btop, fastfetch, kritarc, OpenTabletDriver, starship, mimeapps.list, qt5ct/qt6ct; `local/state/noctalia/settings.toml` and `local/share/luciole/scripts/Set As Wallpaper` are linked into `$XDG_STATE_HOME` / `$XDG_DATA_HOME`.
- `assets/` — `arts/*.txt` (ASCII art), `fonts/*.ttf` (Playfair Display, RougeScript, SendFlowers), `images/*` (Herta PNGs, Kemomimi-chan.gif, nix.png), `cursors/mizuki-psekai-cursor/` (full X11 theme with `index.theme`). Consumed at build time by `font.nix` and `overlays.nix`, not symlinked.
- `docs/images/` — logo and screenshots (`desktop.png`, `lockscreen.png`, `windows.png`, `win11.png`) used only by `README.md`; not part of the system build.
- `secrets/secrets.yaml` — SOPS-encrypted; `.sops.yaml` names the age recipient.

## Wiring rules
- A new `.nix` file in `modules/` or `home/` is inert until added to that directory's `default.nix` import list; same for top-level modules in `flake.nix`.
- The two `default.nix` files are the real map of the system — read them before guessing where a setting lives.

## Dotfile symlink mechanism (important)
- `home/default.nix` sets `homeDirectory = config.users.users.cherr.home`, `dots = "${homeDirectory}/haruka/dots"`, and `mkSymlink = path: config.lib.file.mkOutOfStoreSymlink "${dots}/${path}"`, injected into child modules via `_module.args = { inherit mkSymlink; }`.
- The checkout must live at `~/haruka` or links break. Attribute names in `home/dotfiles.nix` are target XDG paths; values are paths relative to `dots/` (e.g. `"umbriel/config.toml".source = mkSymlink "config/umbriel/config.toml"`).
- Edits to already-registered dotfiles are live (out-of-store symlink), no rebuild. Adding a new one needs a line in `home/dotfiles.nix` / `home/appearance.nix` plus a rebuild. `assets/` changes need a rebuild because they're copied into store derivations.

## Secrets
- `secrets/secrets.yaml` is SOPS-encrypted per `.sops.yaml` (age recipient `age1lq8...`); private key is `/var/lib/sops-nix/key.txt` on the host. Edit with `sops secrets/secrets.yaml` on a machine that has the key; never commit plaintext.
- `modules/sops.nix` declares `wallhaven_api_key` (owner `cherr`) and templates it into `${config.users.users.cherr.home}/.config/noctalia/wallhaven.toml` via `config.sops.placeholder.wallhaven_api_key`.

## Build / verify
- No test suite, CI, or project-specific verify script. Cheapest check: `nix flake check` from repo root.
- System check/switch: `nh os test` / `nh os switch` (`programs.nh.flake` points at `${config.users.users.cherr.home}/haruka`, so `nh` works from any directory), or `nixos-rebuild test --flake .#yozora` / `nixos-rebuild switch --flake .#yozora`.
- Format Nix with `nixfmt` (installed via `modules/packages.nix`; no flake `formatter`). `.prettierrc` only sets `trailingComma: none` — there's no Prettier dependency or script, so treat it as editor config, not an enforced step.
- `.gitignore` excludes `result`, `result-*`, `.direnv`, `**/.nixos-test-history`, `**/*.qcow2`; don't commit build/VM artifacts.

## Gotchas / do-not-break
- Keep both `nixConfig.extra-substituters` (noctalia, nix-gaming, freesmlauncher Cachix) in `flake.nix` and `nix.settings.accept-flake-config = true` in `modules/system.nix`; together they trust those caches and avoid source builds.
- `nixpkgs.config.allowUnfree = true` is deliberate (Brave, Steam, Proton GE, Obsidian, etc.). Removing it breaks eval/build.
- `system.stateVersion` (`modules/system.nix`) and `home.stateVersion` (`home/default.nix`) are both `26.11`; keep in sync, bump only for an intentional migration.
- `networking.firewall.enable = false` and `initialPassword = "password"` are intentional single-machine choices; don't "harden" them in unrelated edits.
- `programs.nh.clean` collects generations Saturdays with `--keep 2 --keep-since 7d`; don't assume old generations persist.
- Remote: `git@github.com:cherrblyria/haruka.git`; `main` plus topic branches (e.g. `umbriel`), merged via GitHub PRs. Commit titles use conventional-style prefixes with optional scopes — verified: `feat:`, `fix:`, `chore:`, `chore(update):`, `refactor:`, `tweak:`, `docs:`, `pkg:`, `perf:`, `clean`, e.g. `feat(shell):`, `fix(umbriel):`. Dependency bumps are `chore: flake update` or `flake.lock: weekly update`.
- `README.md` is screenshots, credits, and "take what you want, modify it" — it documents no commands. Trust flake/config over prose.
